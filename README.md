# 🎟️ Vibecheck

Event booking and ticketing platform. Organizers publish events and sell
tickets online; attendees book seats, receive a QR ticket by email, and get
verified at the gate with a built-in QR scanner.

## Features

- Event creation with ticket types, seat limits, and pricing
- Online booking with payment (test mode)
- QR-code ticket generation and email delivery
- QR scanner page for entry verification
- Organizer dashboard: attendee lists and sales reports

## Tech Stack

- **Backend:** Laravel, MySQL, RESTful API
- **Frontend:** React (attendee app and scanner), Laravel Blade (admin dashboard)
- **Docs:** API documentation in `/docs`

## Project Structure

    backend/    Laravel API and admin dashboard
    frontend/   React app
    docs/       Requirements, use cases, ERD, API docs
